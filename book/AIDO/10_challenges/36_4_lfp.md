# Challenge `LFP` {#challenge-LFP status=ready}

This page documents the historical lane-following-with-pedestrians (`LFP`) challenge from earlier AI-DO releases.

<div figure-id="fig:lane-following-vehicles-intersections-LFP" figure-caption="A Duckiebot following a lane while avoiding pedestrian duckies.">
  <img src="lfp-db19.jpg" style='width:100%;height:auto'/>
</div>

Conceptually, `LFP` extends [Challenge `LF`](#challenge-LF) by adding pedestrian obstacles. The current `ente` workspace does not publish a maintained public `LFP` evaluation queue.

## `LFP` in Simulation {#challenge-aido5_lfp status=ready}

There is no maintained public `ente` simulation queue for `LFP` in this workspace.

If you want to explore similar ideas today, start from the maintained LF runtime and adapt it privately:

- [Challenge `LF`](#challenge-LF)
- [PyTorch template](#pytorch-template)
- [ROS template](#ros-template)
- `dts challenges evaluate --challenge aido-LF-sim-validation`

## Templates {status=draft}

The maintained repo set in this workspace does not include a dedicated `LFP` template. Use one of the maintained LF templates or baselines instead, then add pedestrian-handling logic in your own project.
